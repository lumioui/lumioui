# Code of conduct

LumioUI is a place to build good things together. Be kind, assume good intent, and keep discussion about the work.

Not okay here: harassment, personal attacks, discriminatory language or imagery, sharing someone's private information, and sustained disruption of discussions.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block people who keep breaking them.

To report a problem, email hello@lumioui.com. Reports are read by the maintainers and kept private.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
